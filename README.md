MediStock — Pharmacy Inventory Management System

A full-stack pharmacy management system for managing medicines, inventory, customers, suppliers, billing, invoices, and reports with role-based access for Admin and Pharmacist users.

Technical Stack

Frontend

- React.js
- React Router
- Tailwind CSS
- Context API
- Axios
- Vite
- React Icons / Lucide React

Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcrypt
- CORS

Deployment

- Vercel — Frontend
- Render — Backend
- MongoDB Atlas — Database

Use Cases

Admin

- Manage medicines
- Manage suppliers
- Manage customers
- Manage inventory
- Manage users
- Create and manage bills
- Generate invoices
- View sales and profit reports
- Monitor stock levels and expiry
- View stock movement

Pharmacist

- View medicines
- Search and filter medicines
- View customers
- Manage customer billing
- Generate invoices
- Track available stock

Key Features

- JWT-based authentication
- Role-based protected routes
- Medicine CRUD operations
- Medicine search and pagination
- Filter by category, company, and supplier
- Inventory stock management
- Stock increase and adjustment
- Low-stock and out-of-stock tracking
- Expired and near-expiry medicine tracking
- Stock movement tracking
- Customer management
- Customer purchase history
- Supplier management
- Billing with multiple medicines
- Discount and GST calculation
- Cash, UPI, and Card payment methods
- Invoice generation and printing
- Today's, weekly, and monthly sales reports
- Profit and purchase reports
- Best-selling medicine reports
- Responsive dashboard and management UI
- Production deployment with Vercel and Render
